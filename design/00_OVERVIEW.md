# 00. 개요 (PCS)

**PCS** = 설비/센서(SCADA) 데이터 **거버넌스 파이프라인**.

## 문제
담당자마다 같은 지표의 정의가 다르다(예: "가동률"의 분모·기간·필터 상이). 정의가 코드/시트/머릿속에 흩어져 재현·검증 불가.

## 목적
지표 정의를 **표준화**한다. 수단 3종:
- **SQL 중심 관리** — 정의를 dbt 모델(SQL)로 단일화.
- **비즈니스 그래프** — 지표 간 계보/관계는 dbt `ref()` 그래프 + OpenMetadata lineage 로 표현.
- **문서화** — 스키마/테이블/온톨로지 사전화.

## 범위
| 대상 | 포함 |
|---|---|
| 원천 | SCADA(Oracle) 설비·센서 트레이스 |
| 가공 | 메달리온 SRC→LND→SLV→CORE→GOLD |
| 산출 | 설비/센서 KPI 데이터 프로덕트 |
| 관측 | CTL 메트릭 · OpenLineage · OpenMetadata |

## 이해관계자
- 데이터 엔지니어 / 분석가 / 설비 운영 담당자.
