# workspace/ — 지시·기록 (전원 + Agent)

| 폴더 | 무엇 |
|---|---|
| `instructions/` | 작업 지시서 — 목표/범위/제약/완료조건. Agent는 여기서 일을 받는다 |
| `pdca/<feature>/` | plan→do→check→act 기록 (작업 1건당 1폴더) |
| `patterns/` | 성공 패턴 승격 (check에서 검증된 것만) |
| `mistakes/` | 실패 교훈 — 근본 원인과 예방책 |

## 규칙
1. 지시서 없는 작업 금지 — 구두 요청도 instructions에 남긴 뒤 착수.
2. pdca는 작업 중 갱신한다 (끝나고 몰아 쓰지 말 것). do.md에는 에러·시행착오·해결을 시간순으로.
3. 같은 실수 2회 = mistakes 문서화 대상. 패턴 승격은 실제 재사용이 확인된 뒤에.
4. 완료된 pdca는 보존 — 삭제하지 않는다 (프로젝트 이력).
